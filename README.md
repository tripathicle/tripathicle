DevOps & Cloud Engineer with **5+ years of experience** designing, automating, and securing cloud infrastructure and CI/CD pipelines at scale. I've led DevOps for enterprise-grade platforms in the automotive domain and delivered measurable wins — faster deployments, stronger compliance, higher reliability — through automation and cloud-native solutions.

## 🌐  Projects

### 🏗️ Hub-Spoke Landing Zone

<a href="https://github.com/tripathicle/Workload-Landing-Zone" target="_blank">
  <img src="https://github.com/tripathicle/tripathicle/blob/main/hub%20and%20spoke%20image-1.png" alt="Hub-Spoke Landing Zone" width="1000" />
</a>

Production-grade, zero-trust Azure platform hosting workloads on a secure, observable, and resilient **Hub-Spoke architecture** with **150+ Terraform resources**.

**Highlights:**
- 4 Resource Groups (network, platform, app, data)
- Bi-directional VNet peering between Hub & Spoke
- WAF_v2 Application Gateway with OWASP 3.2 Prevention mode
- Azure SQL via Private Link (public access disabled)
- Azure Bastion for zero-trust admin access
- 15+ reusable Terraform modules

<br>

### 🛒 AgriKart

<a href="https://github.com/tripathicle/Agrikart" target="_blank">
  <img src="https://github.com/tripathicle/tripathicle/blob/main/agri%20kart%20image-1.png" alt="AgriKart" width="1000" />
</a>

Microservices-based agriculture platform — marketplace, tractor rentals, weather, and milk delivery requests. Connects farmers, traders, and service providers in one unified web platform.

**Highlights:**
- **Frontend:** React + TypeScript + Vite + Tailwind CSS + Redux Toolkit
- **Backend:** Node.js + Express.js (microservices architecture)
- **Database:** MySQL with normalized schema
- **Integrations:** OpenWeatherMap API, JWT authentication
- **DevOps:** GitHub Actions CI/CD, Docker containerization (planned)
